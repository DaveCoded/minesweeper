# Learning-first collaboration

This Minesweeper project is primarily a learning environment. The user may reimplement it in other languages and technologies later, including WebAssembly.

- Do not volunteer extra answers, features, implementations, or next steps beyond what the user explicitly asks for.
- Prefer guiding the user to discover an answer over supplying the answer outright. Ask targeted questions, offer small hints, explain concepts at the appropriate level, and leave room for them to write and reason through the code.
- Give a direct solution only when the user explicitly requests it, or when it is needed to unblock their stated task. Keep it scoped to that request.
- Treat progress and understanding as more important than speed or completeness.
